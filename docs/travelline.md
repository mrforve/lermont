# TravelLine

Перенесено с hotel-lermont.ru на dev.hotel-lermont.ru 26.10.2026.

Контекст: `TL-INT-hotel-lermont-new`, язык `ru`. Источники — действующие HTML главной, `/booking/`, `/lk/`, `/otzyvy/` и PHP-шаблоны WordPress (только чтение).

- Главная: `tl-search-form` и закреплённая версия `tl-search-form-sticky`. На мобильных используется основная адаптивная форма.
- Внутренние страницы: `tl-search-form-inner`; исключены сама страница бронирования и служебные страницы регистрации/авторизации Laravel.
- `/booking`: `booking-form` в `tl-booking-form`, параметры URL `date`, `nights`, `room-type`, `be-offer` и другие параметры TravelLine сохраняются.
- `/lk`: `guest-account` в `tl-guest-account`. Кнопка клуба на главной направляет сюда.
- `/otzyvy`: `reviews-widget` в `tl-reviews-widget`, как на исходной странице отзывов.
- `reputation-widget` не включён: его инициализация на исходной главной закомментирована.

Единый загрузчик `resources/js/components/travelline.js` подключён через `app.js`. Он регистрирует только существующие контейнеры, предотвращает дубли очереди и загружает SDK с `ru-ibe.tlintegration.ru`, `ibe.tlintegration.ru`, `ibe.tlintegration.com`. Как на исходном сайте, следующий адрес используется и при ошибке запроса, и если ответ не создал глобальный объект TL. Если все источники недоступны, посетителю показывается ссылка на соответствующий модуль основного сайта.

Миграция `2026_10_26_090000_add_travelline_room_type_id` добавляет эти значения. ID можно изменить в форме типа номера в секции TravelLine. `RoomType::booking_url` формирует локальную ссылку `/booking?room-type=...`; без ID используется обычная страница бронирования.

При развёртывании: `php artisan migrate --force`, `npm run build`. Основной WordPress-сайт и тарифы TravelLine не изменяются.
