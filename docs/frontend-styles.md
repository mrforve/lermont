# Стили фронтэнда

Единая точка входа — resources/css/app.css. Она импортирует базовый lermont.css, components/*.css и pages/*.css. В layout остаётся только @vite для CSS проекта; Bootstrap и шрифты подключаются отдельно как внешние библиотеки.

Страничные правила новостей, акций, завтраков и каталога ограничены корневым классом страницы через :where(), без повышения специфичности. Исходный порядок деклараций сохранён. Удалены 149 селекторов без ссылок в шаблонах, JavaScript и актуальном контенте БД, а также полностью перекрытый старый базовый блок каталога. Удалён неиспользуемый стартовый шаблон welcome с резервным встроенным Tailwind CSS.

Сохранены стили Swiper, TravelLine, динамических состояний JS, типов блоков и вариантов галереи из админки. Из шаблонов вынесены блоки <style> и фиксированные CSS-декларации. В style-атрибутах остаются только значения CSS-переменных, вычисляемые сервером: адреса изображений и настройки размеров из админки.

Сборка: npm run build. При развёртывании существующей БД выполните php artisan migrate --force: миграция 2026_10_25_210000_remove_consumer_corner_stylesheet_link удаляет только устаревшее CSS-подключение из HTML-блока «Уголка потребителя». PDF, изображения и остальное содержимое не изменяются.

Из public/css удалены шесть перенесённых файлов. Скомпилированные public/build не хранятся в Git и должны собираться при развёртывании. Файлы и стили Filament не изменяются.
